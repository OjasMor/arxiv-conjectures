Let $G \leq \Sym(n)$ be transitive with $n > 1$.
Does $G$ have a derangement of prime or prime-squared order?

VERDICT: DISPROVED

STATEMENT: “Let \(G \leq \operatorname{Sym}(n)\) be transitive with \(n > 1\). Does \(G\) have a derangement of prime or prime-squared order?” No. The action below has derangements of order \(8\), but none of prime or prime-squared order.

DEGENERATE: no — this is a faithful transitive action of degree \(2{,}239{,}488\). Its points are affine cosets, and a fixed point means a coset fixed setwise.

ARGUMENT:

As small checks on the definitions, I enumerated the paper’s \(\operatorname{AGL}_1(9)\) example on the 12 affine lines of \(\mathbb F_3^2\). Among the 72 elements I found 18 derangements of order \(4\), 36 of order \(8\), and none of prime order. I also recovered the stated 48 derangements of order \(7\) among the 168 elements of \(\operatorname{GL}_3(2)\) acting on the seven nonzero vectors.

**The counterexample.** Write \(U_j=A^jU\). The finite calculations below verify that \(A\) has order \(432\) modulo \(2592\), and that \(U_0\) has orbit length \(12\) under \(A\). Thus \(A\) cycles the 12 directions \(U_j\), and translations act transitively on the cosets of each direction. The stated action is transitive, of degree
\[
12\frac{2592^2}{|U|}=12\frac{2592^2}{36}=2{,}239{,}488.
\]

The action of the affine group \(V\rtimes\langle A\rangle\) on these cosets is **faithful**: since \(U_0\cap U_1=0\), each \(v\in V\) is the unique intersection point of \(v+U_0\) and \(v+U_1\). An affine map fixing every coset therefore fixes every vector. In particular, we can compute element orders in the affine group itself. Its order is \(2592^2\cdot432\), whose only prime divisors are \(2\) and \(3\). It suffices to show that every \(g\) satisfying \(g^4=1\) or \(g^9=1\) fixes a coset.

**Why the local checks suffice.** Write \(g(x)=A^kx+v\), with \(0\le k<432\). Suppose \(g^h=1\), where \(h=4\) or \(9\). Then
\[
432/h\mid k,\qquad S_{k,h}v=0,\qquad
S_{k,h}=I+A^k+\cdots+A^{(h-1)k}.
\]
In either case \(12\mid k\), so \(A^k\) preserves every direction \(U_j\).

Use \(2592=32\cdot81\) to decompose \(V=V_{32}\times V_{81}\), where \(V_d=(\mathbb Z/d\mathbb Z)^2\). Each \(U_j\) is the product of its two projections \(U_{j,d}\), since their orders \(4\) and \(9\) are coprime.

Take \(d=32\) for \(h=4\), and \(d=81\) for \(h=9\). The verifier checks, for **every** allowed \(k\), that
\[
\ker(S_{k,h}\text{ on } V_d)\ \subseteq\ \bigcup_{j=0}^{11} U_{j,d}.
\]
Consequently \(v_d\in U_{j,d}\) for some \(j\). On this component \(g\) preserves \(U_{j,d}\) itself.

The same \(j\) works on the other component \(V_{d'}\): there \(g\) has a fixed vector \(w\), since its order divides \(h\) and \(|V_{d'}|\) is coprime to the prime dividing \(h\). Indeed, without a fixed vector every orbit length would be divisible by that prime. Since \(A^k\) preserves \(U_{j,d'}\), the coset \(w+U_{j,d'}\) is fixed setwise. Taking the product gives a fixed coset of \(U_j\) in \(V\).

This excludes all four orders \(2,3,4,9\). In contrast, \(A^{54}\) has order \(8\) and shifts the 12 directions by \(6\), so it is a derangement.

**Verification code** (standard Python). It suffices to store the first column \((a,b)\) of each \(A^j\): the second is \((b,a+b)\), because \(e_2=Ae_1\). The same column rule holds for the sum \(S_{k,h}\).

```python
from math import gcd
from itertools import product

N = 2592

def powers(d):
    a, b = 1, 0
    P = []
    while not P or (a, b) != (1, 0):
        P.append((a, b))
        a, b = b, (a + b) % d
    return P

M = len(powers(N))
# U_j = U iff A^j(72,0) is a generator of U.
L = next(j for j, (a, b) in enumerate(powers(N))
         if j and (72*b) % N == 0 and gcd(a, 36) == 1)
print("order(A), directions, degree:", M, L, L*N*N//36)
assert (M, L) == (432, 12)

for d, h in [(32, 4), (81, 9)]:
    P = powers(d)
    U = {((72*i*a) % d, (72*i*b) % d)
         for a, b in P[:L] for i in range(h)}
    sizes = []
    for k in range(0, M, M//h):
        assert k % L == 0
        s, t = map(sum, zip(*(P[(k*i) % len(P)] for i in range(h))))
        K = {(x, y) for x, y in product(range(d), repeat=2)
             if (s*x + t*y) % d == 0 and (t*x + (s+t)*y) % d == 0}
        assert K <= U
        sizes.append(len(K))
    print("modulus, h, covered vectors, kernel sizes:", d, h, len(U), sizes)
```
